## Implementation Steps

2. [ ] Xây dựng module `analysis.js`: 
   - [ ] Tự động xác định vùng Hỗ trợ/Kháng cự mạnh.
   - [ ] Vẽ Fibonacci thoái lui từ đỉnh/đáy gần nhất.
3. [ ] Cập nhật UI: Hiển thị mốc TP1, TP2, TP3 rõ ràng khi phân tích mã.
